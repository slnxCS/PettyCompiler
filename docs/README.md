# PettyLang Compiler — техническая документация

PettyLang — небольшой статически типизированный объектно-ориентированный язык. Этот репозиторий содержит
**компилятор** PettyLang, написанный на C# (.NET 10). Компилятор переводит исходный текст (`*.pt`) в
**байткод PTVM** — бинарный формат для стековой виртуальной машины PettyLang (сама VM — отдельный проект).

```
 исходный код ─▶ Lexer ─▶ Parser ─▶ AST ─▶ Analyzer ─▶ Compiler ─▶ файл байткода PTVM
   *.pt         токены           дерево   символы,      байты
                                          типы, ID,
                                          пул констант
```

## Ключевые факты

| Параметр | Значение |
|---|---|
| Язык реализации | C# 13, .NET 10 (`net10.0`) |
| Версия компилятора | `0.1` (`Program.VERSION`) |
| Версия байткода | `1.392` (`HeaderCompiler.BYTECODE_VERSION`, хранится как `float32`) |
| Сигнатура файла | ASCII `[PTVM]` |
| Порядок байт | little-endian (как `BitConverter` на x86/x64/ARM64) |
| Точка входа программы | функция `Main()` без параметров, возвращающая `void` |
| Командная строка | `PettyLang -i <исходник> -o <байткод>` (библиотека `System.CommandLine`) |
| Тесты | NUnit 4, проект `Tests/PettyCompilerTests`, 273 теста |

## Минимальная программа

```petty
class Counter : {
    var value = 0;

    func next() : int32 {
        self.value = self.value + 1;
        return self.value;
    }
}

func Main() {
    var c = Counter();
    print(c.next());   # 1
    print(c.next());   # 2
}
```

Документация описывает компилятор с байткодом версии 1.392 (длина перед каждой функцией вместо
завершающего `HALT`); тело `if` может быть одной инструкцией без фигурных скобок.
